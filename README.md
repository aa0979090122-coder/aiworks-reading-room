# SEO 文章思考

## 現行閱讀方式（2026-11-02）

本節依使用者本次要求更新，優先於下方歷史設計與維護紀錄。

- 網站只留「最近有什麼」與「全部素材」，移除文章總覽、深度閱讀與我的知識庫的頁面入口。歷史來源、原有筆記、Research 與個人紀錄保留，不清除資料。
- 全部素材按原始發表日排列，顯示台北日期今天及往前 13 天。新聞、社群、播客與研究使用相同範圍；重新核對、補讀與編輯日期不延長顯示期限。首頁依有來源支持的實際進展日期判斷新近程度。
- 正文只顯示中文整理：摘要、背景、重點、來源限制與原文連結，參考舊新聞文字的清楚層次。保留必要的產品名稱及術語，移除重複的英文摘要與左右雙語版面。
- 保留每題的推薦閱讀、其他來源、事件脈絡與跨來源延伸閱讀；較舊來源仍可由延伸閱讀開啟，不受一般列表的 14 天限制，也不因該項目被移出列表就刪掉連結。
- 使用者可直接按「刪除」，不必填理由；當下提供復原，也可由「已刪除」找回。刪除只記錄 removed 狀態，不移除來源或人工筆記；不得從未填理由的刪除推定特定內容偏好。
- 「有興趣」與看過簡介、看過原文、追問各自保存。明確標記的興趣可從「有興趣的」回看先前內容；主要列表仍維持近 14 天。既有紀錄沿用相同瀏覽器儲存位置，備份、匯入與複製回饋改放頁首的「閱讀紀錄」。
- 每日維護繼續主動發現有用的新消息，保留來源查證與來源缺口；不再要求日常閱讀先進知識庫或 Research。舊筆記保留，毋須每天新增英文筆記。讀不到最新回饋時，明確記錄缺口。

文章總覽為預設首頁，以目的、服務、客群、問題與文章的心智圖逐層展開。保留父節點，可拖曳與縮放。官網文章依正文區分主要回答與部分回答；Research 可從素材加入或貼網址，獨立保存在瀏覽器並可匯出／合併匯入。

深度閱讀原地展開跨來源摘要、重點與來源限制。全部素材包含歷史、已讀與收藏，可依來源與面向篩選；OpenAI 官網來源可直接回查。原社群、Podcast 與新聞入口保留於「依來源閱讀」。原社群閱讀中，左邊 X 官方預覽或英文資料，右邊中文摘要與操作。Podcast、新聞、深度資料同樣採左右閱讀；手機上下排列。沒有取得全文授權的文章提供 English brief 或短節錄與原始連結。版面偏好見 DESIGN.md；選文與每日維護見 SOURCES.md。

一般社群貼文與新聞顯示近 14 天；企業案例與高層次社群討論回看半年。Podcast 和深度研究保留較早的有用資料。歷史來源仍在 content.json，可從已讀與歷史查看。深度選題的 readingSets 由日常議題與收藏興趣逐步形成，把已有來源組成大章節；補找的來源也先加入日常入口。深度閱讀直接展開同一份素材的摘要與重點，保留原始連結；收藏與筆記仍沿用既有資料。半年補讀保留原始日期，先在日常入口顯示 14 天，歷史仍可查閱。過去 24 小時摘要依發布時間，不使用匯入時間。

## 知識庫

沿用 `aiworks-reading-room-feedback-v1`。收藏從閱讀頁移到知識庫，保存來源快照；取消收藏保留筆記與 Markdown。沒幫助須填理由。手動章節與人工想法優先保留。

本機工具只監聽這台電腦的 127.0.0.1:8766。公開頁可將收藏、理由與瀏覽器筆記送進本機 inbox；回應只包含接受成功，不能讀取本機資料。直接開啟本機版後，完整筆記直接從 Markdown 讀取，每五秒重讀。本機頁面的內文直接讀取 Markdown；公開頁的內文與下載檔由相同 Markdown 產生。

正式資料在專案 `02_內容資料/reading-knowledge/`：`index.md` 是索引，`notes/note-*.md` 是可直接改的筆記，`feedback.json` 保存閱讀狀態、人工想法與章節，`feedback.md` 供每日選文檢視。修改筆記保留開頭 reading-room 註記。取消收藏保留 Markdown。標記為 public 的筆記內文與手動章節同步公開版；閱讀狀態、略過理由及備份不部署。

每日台北時間 09:30 的既有維護會核對收藏並深化 Markdown，再執行 04_維護工具/build_reading_knowledge.py，同步公開版。13:30、18:30 只補查當天未完成事項；來源、必要維護與公開版本完整驗證後，保存完成證據並移除當天後續補跑，保留隔天 09:30。已完整核對且無新內容也算完成，不重複部署。每次排程使用獨立新對話交付結果。直接改 MD，本機頁面每五秒重讀；公開版需在每日維護或要求更新時部署。頁面本身不在點擊收藏時呼叫模型。筆記內文解釋概念與關聯，連到另一則收藏；來源網址另列。人工想法、段落與手動分類保留，深化前保存私有上一版。

本機服務的隨機權杖只發給本機頁；資料讀寫 API 拒絕公開 origin，即使有權杖也不能讀。inbox 只允許既有網站 origin 提交 JSON，不回傳私人資料；服務沒有任意檔案讀取入口。瀏覽器阻擋本機提交時，收藏仍存於原瀏覽器，可匯出／匯入本機版，或直接在本機版閱讀。不要繞過瀏覽器安全提示。

## 文章總覽（2026-10-13）

首頁以可拖曳與縮放的心智圖呈現目的、服務、客群、問題及歷史文章。逐層展開保留父節點；不設每週選題區與側邊 Profile。文章依官網正文區分主要與部分回答，舊網址讀取失敗保留紀錄。素材與深度閱讀可加入指定問題的 Research，也可貼網址；Research、展開狀態與想法沿用原瀏覽器資料並可備份。來源分類置於全部素材，摘要在當頁展開。


## 情境與追問（2026-10-13）

文章切角從使用情境出發：誰在什麼時候點開，讀後要做什麼判斷，本篇先處理哪一件事。同一概念可在不同情境下重述；舊文對照用來延伸與連結，不因談過就排除選題。

新增或複查素材時，從具體主張追問原因、誘因、適用條件、反例、資料取得方式與決策用途。查到的初步回答要連到原始證據，區分已有依據、僅有部分依據和仍待查證；沒有答案時保留問題與下一步查詢，不補造結論。優先核對實際回覆，區分原文直接回應、同議題討論和單純轉貼。

Research 可保留多個情境候選，選定後仍可修改，並可把素材中的追問帶進題目。頁面顯示的是已整理的問題與來源，不在按鈕點擊時即時呼叫 AI 搜尋。AI 後續研究時依這份文件繼續補答案與追問。
