# Aiworks 洞察選讀

桌面優先的單頁閱讀網站。使用者先閱讀 X 原始貼文，再自行展開中文翻譯或重點；下方依序是 Podcast 導讀與企業 AI 新聞。資料由 `content.json` 管理，GitHub Pages 可直接發布倉庫根目錄。

## 編輯與更新

- X：只收錄能連到企業採購、導入、治理、工作流程或組織變化的原始貼文。優先追發布者本人與實際執行者，也透過主題搜尋發現名單外的公司。頁面只顯示原文與按需展開的中文；篩選理由不放入畫面。
- Podcast：按單集挑選，不要求每個節目都出現在每期。根據已查閱的原始節目頁、章節或逐字稿撰寫導讀。尚未取得完整逐字稿時，不將節目介紹寫成已聽完的結論。
- 新聞：從 `02-content/news/latest-news.md` 與原始來源挑選企業能用於判斷採購、部署或擴大採用的項目。一般服務故障、零散 bug、與目標讀者無直接關係的監管消息不進首頁；重大事件仍可在原新聞檔保留。
- 更新資料時維持原始 URL、日期與來源，改寫短摘要前核對原文。`editionDate` 表示選讀更新日期，不代表每筆內容都是當日發布。

網站沒有帳號與資料庫。這一版是人工核對後的選讀，不會自行抓取 X 或 Podcast，也不會暗示內容已即時同步。
