# Aiworks 資訊情報站

桌面優先的閱讀網站，包含 X 貼文、Podcast、新聞、深度選題與我的知識庫。X 卡片在桌面版左側顯示官方原文嵌入，右側顯示中文重點、已核實的公開回覆觀察與操作；窄螢幕改為上下排列，並提供直達原貼與留言的連結；嵌入無法載入時保留英文節錄。YouTube 單集可在頁內播放。

## 內容與時效

- X 的公司案例可保留近六個月；其他 X 貼文與新聞顯示最近 14 個日曆日尚未標記已讀或「沒幫助」的內容，依發布時間排序。超過期限的項目仍保留在 `content.json`，可從「查看已讀與其他內容」找到；收藏會移入「我的知識庫」，從待讀與歷史清單移出。
- Podcast：按單集挑選，包含近期訪談與仍有參考價值的舊集，不套用 14 天期限。根據原始節目頁、章節或可查閱的逐字稿寫導讀。找到英文逐字稿時提供官方閱讀連結，並標明是否需要登入；若 YouTube 原片另有可讀的英文自動轉錄稿，也提供入口並標示辨識誤差。不在本站重製第三方逐字稿全文。尚未取得完整逐字稿時，不將節目介紹寫成已聽完的結論。
- 新聞：優先呈現企業採購、部署、擴大採用、衡量成果與員工使用的素材；每則分成「這篇在談什麼」與「主要內容」。一般服務故障、零散 bug 與無關的監管消息不進首頁。
- 深度選題：收錄可延伸成文章的企業實例與研究報告，標明原始資料、可寫角度和公開資料的限制。這是閱讀與選題資料，尚未確認文章方向；不套用新聞的 14 天期限。
- X：優先當事人、實際執行者和企業管理者；產品更新只有能連到採購或採用判斷時才收錄。留言觀察只根據逐則核實的公開可見回覆，不將少量回覆稱為整體風向；看不到回覆時不填入猜測。篩選理由不放進閱讀畫面。

已讀、沒幫助、收藏、逐篇筆記及總筆記儲存在瀏覽器的 `localStorage`。頁面不設帳號或資料庫，因此不同瀏覽器與裝置之間不會同步。使用者可在「我的筆記」複製回饋並貼到對話，供下一輪選文調整。標記「沒幫助」本身不會自動更改後續選文，需在內容更新時人工檢視回饋。

`content.json` 是人工核對後的資料，不會自行抓取 X 或 Podcast。`editionDate` 是資料更新日，不代表每筆內容都在當日發布。GitHub Pages 可直接發布倉庫根目錄。

可沿用的搜尋與核對管道記在 [SOURCES.md](./SOURCES.md)。本站是後續文章選材的日常入口；原有獨立每日新聞排程已停用。


## 收藏與知識庫

沿用原本的 `aiworks-reading-room-feedback-v1` 儲存資料，既有收藏自動遷入知識庫，不需重新按收藏。收藏時保留來源快照，未來來源不在內容清單時仍能閱讀。取消收藏會移回閱讀清單，逐篇筆記保留。

知識庫按主題分章，每筆包含來源重點、限制、待追問問題、原文連結與相關收藏。`content.json` 的 `knowledge` 欄位由內容維護時核對與整理，指定 `primary`、`themes`、`concepts`、`outcome` 與可選的 `related`（網址與關聯理由）；缺少標註的舊資料才用文字規則暫時歸類。使用者手動指定的章節優先，不被自動分類覆蓋。新收藏即時計算與既有收藏的連結，關係只代表共同問題或可供比較，不能視為因果或相互佐證。

目前為靜態網站：瀏覽器即時整理已核對的摘要與標註，沒有背景語言模型或跨裝置資料庫。每日研究負責更新選文與來源標註；個人筆記不會上傳公開 GitHub 倉庫。提供全文搜尋、資料類型篩選、逐篇及章節筆記、Markdown 匯出、JSON 備份與合併匯入。匯入保留較新紀錄，不清空現有資料。
