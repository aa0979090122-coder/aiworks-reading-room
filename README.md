# Aiworks 資訊情報站

桌面優先的閱讀網站，將 X 貼文、Podcast 單集與企業 AI 新聞放在三個切換標籤。X 卡片依序顯示官方原文嵌入、中文重點與已核實的公開回覆觀察，並提供直達原貼與留言的連結；嵌入無法載入時保留英文節錄。YouTube 單集可在頁內播放。

## 內容與時效

- X 的公司案例可保留近六個月；其他 X 貼文與新聞顯示最近 14 個日曆日尚未標記已讀或「沒幫助」的內容，依發布時間排序。超過期限的項目仍保留在 `content.json`，可從「查看已讀與其他內容」找到；收藏會持續留在首頁。
- Podcast：按單集挑選，包含近期訪談與仍有參考價值的舊集，不套用 14 天期限。根據原始節目頁、章節或可查閱的逐字稿寫導讀。找到英文逐字稿時提供官方閱讀連結，並標明是否需要登入；不在本站重製第三方逐字稿全文。尚未取得完整逐字稿時，不將節目介紹寫成已聽完的結論。
- 新聞：優先呈現企業採購、部署、擴大採用、衡量成果與員工使用的素材；每則分成「這篇在談什麼」與「主要內容」。一般服務故障、零散 bug 與無關的監管消息不進首頁。
- X：優先當事人、實際執行者和企業管理者；產品更新只有能連到採購或採用判斷時才收錄。留言觀察只根據逐則核實的公開可見回覆，不將少量回覆稱為整體風向；看不到回覆時不填入猜測。篩選理由不放進閱讀畫面。

已讀、沒幫助、收藏、逐篇筆記及總筆記儲存在瀏覽器的 `localStorage`。頁面不設帳號或資料庫，因此不同瀏覽器與裝置之間不會同步。使用者可在「我的筆記」複製回饋並貼到對話，供下一輪選文調整。標記「沒幫助」本身不會自動更改後續選文，需在內容更新時人工檢視回饋。

`content.json` 是人工核對後的資料，不會自行抓取 X 或 Podcast。`editionDate` 是資料更新日，不代表每筆內容都在當日發布。GitHub Pages 可直接發布倉庫根目錄。

可沿用的搜尋與核對管道記在 [SOURCES.md](./SOURCES.md)。本站是後續文章選材的日常入口；原有獨立每日新聞排程已停用。
